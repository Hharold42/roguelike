# Мир 8×8 + персонаж от первого лица

Перезапуск проекта: от roguelike-survivor оставлен мир — генерация рельефа
с холмами, запечённый закатный свет и воксельная трава — плюс персонаж
от первого лица со стандартной физикой и видимым телом (GLB-модель).
Прежний игровой слой (враги, оружие, магазин, HUD) заархивирован в
`game-archive-2026-10-07.zip` на Рабочем столе и удалён из исходников.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # tsc + vite → dist/
npm run preview   # раздача dist/ (с --host — по Wi-Fi)
```

Управление: клик — захват мыши, WASD — движение, Space — прыжок,
C / Ctrl — присед, Shift — спринт, Esc — отпустить курсор.
Сид мира — `?seed=123` (иначе случайный, печатается в отладочной плашке).

## Персонаж

`src/player.ts` — физика от первого лица: разгон/торможение на земле,
слабое подруливание в воздухе, «не лунная» дуга прыжка (взлёт мягче
падения, зависание у вершины, обрезка при отпускании клавиши), coyote
time 0.1 с и буфер прыжка 0.12 с, присед (скорость ×0.5, взгляд ниже),
спринт ×1.6, амортизация взгляда при жёстком приземлении. Опора —
аналитический рельеф; позиция клампится границами мира (невидимая стена).

`src/bodyView.ts` — тело: `public/hero_inf.glb` на отдельном прозрачном
WebGL-слое поверх софтверного кадра (Babylon). Камера слоя зеркалит
софтверную камеру (позиция, yaw/pitch, вертикальный FOV), поэтому при
взгляде вниз видны свой торс и ноги; тело сдвинуто на 0.18 ю назад,
чтобы торс не залезал в объектив. Голова скрыта (кость схлопнута).
Модель нормализуется до роста 1.8 ю, ступни в нуле; скелет без анимаций
ходьбы, поэтому шаг/прыжок/присед/дыхание играет процедурный риг
(`humanoidRig.ts`, распознаёт скелет геометрически) по состоянию
движения (`motion.ts` MotionState). Свет слоя повторяет закатное солнце
мира. Если WebGL или файла нет — игра просто идёт без тела.

## Мир

Фиксированный квадрат **8×8 чанков** (чанк = 16×16 колонн по 2×2 юнита,
итого 256×256 юнитов), центр — спавн (0, 0), там всегда ровная площадка.
За границей мира колонн нет — рендер оставляет дымку в цвете тумана:
мир-остров в молоке. Аналитическая высота (`terrain.getHeight`) доступна
и за краем.

`src/terrain.ts` — рельеф как чистая функция от координат: fBm-шум холмов
(ампл. 2.6) + крупные возвышенности (3.2), плавное сглаживание к спавну,
низкочастотный биом «влажности» (выжженная олива ↔ сырая зелень).

`src/soft/columnMap.ts` — мир запекается в карту колонн один раз на старте
(`bakeWorld`, 64 тайла): высота, свет, цвет. Свет запечённый — склон по
нормали рельефа плюс **тени от холмов** (марш луча к низкому солнцу по
фартуку тайла). Цвет — полосы палитры по высоте с плавными переходами,
тонировка биомом и снег на вершинах (от 3.6 ю).

## Рендер

`src/soft/renderer.ts` — софтверный voxel-space (CPU, без GPU и
зависимостей): поэкранно-столбцовый марш лучей, спаны снизу вверх, каждый
пиксель пишется один раз, глубина — в z-buffer. Земля гладкая: высота,
свет и цвет билинейно интерполируются между колоннами (`sampleGround`
воспроизводит аналитический рельеф точно). Вблизи — крапчатая текстура
(хеш от координат, две октавы, затухает к 35 ю). Наклон камеры — истинный
(±66°): ньютоновская поправка ставит сэмпл точно в лучевую плоскость
столбца, мир поворачивается без «плавания». Небо — градиент к истинному
горизонту с гало солнца; туман экспоненциальный по таблице (Z_FAR 170 ю).
Всё проходит через палитру 6 уровней на канал с дизерингом Байера 4×4;
внутреннее разрешение 240 px по вертикали, растяжение без сглаживания.

`src/soft/grass.ts` — трава: каждая клетка 1×1 юнит детерминированно
порождает 5 колосков (хеш от координат — не «ползут» за камерой). Колосок —
линия основание→кончик: основание в тени, кончик светлый и сужается.
Ветер: бегущая волна + поперечная рябь + порывы, фаза колоска из хеша.
`trample(x, z, r)` гнёт колоски от камеры (сила и направление, exp-
распрямление за ~2 с). Радиус поля 26 ю, к краю колоски низеют — без
pop-in. Не растёт на снегу и вне мира; густота и высота — по биому
(сырые низины густые, сухие полосы — редкая поросль).

## Структура

```
index.html         канвас + подсказка + отладочная плашка
public/
  hero_inf.glb     модель персонажа (скелет, 110 костей)
src/
  main.ts          цикл кадра: ввод, физика, рендер мира, тело
  style.css        стили страницы
  terrain.ts       рельеф: холмы, возвышенности, биом (чистые функции)
  player.ts        FPS-физика: ходьба, прыжок, присед, спринт
  bodyView.ts      тело персонажа: прозрачный WebGL-слой с GLB поверх кадра
  humanoidRig.ts   распознавание скелета и процедурная анимация по костям
  motion.ts        MotionState — состояние движения для анимации
  soft/
    columnMap.ts   мир 8×8 чанков: запечённые высота/свет/цвет, билинейный сэмпл
    renderer.ts    voxel-space рендерер: небо, мир, трава
    grass.ts       поле колосков: ветер, приминание
    gfx.ts         Z_FAR, палитра, Байер, таблица тумана
```

Зависимости: @babylonjs/core + @babylonjs/loaders — только для слоя тела
(мир рендерится чистым CPU-кодом без библиотек).
